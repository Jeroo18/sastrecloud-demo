# SastreCloud — demo del front end

Demostración estática de los micro-frontends Angular 21 (shell + remoto `taller` con Native Federation).

**Ver en línea:** https://jeroo18.github.io/sastrecloud-demo/

Funciona sin servidor: un backend simulado en el navegador reemplaza al BFF y a Firebase, con datos
de ejemplo guardados en `localStorage`. "Reiniciar datos" (barra amarilla) vuelve al estado inicial.
